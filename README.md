# Дом, увитый плющом — проект 2

Самостоятельная вторая версия учебного лендинга. Статические HTML, CSS и JavaScript; сборка и серверная часть не нужны. Изображения, шрифты и звуковые записи находятся в assets. Первая версия сохранена отдельно и не изменена.

## Локальный просмотр

В этой папке выполните `python3 -m http.server 4174` и откройте http://localhost:4174/ . Для загрузки звуков используйте локальный сервер, а не открытие index.html через file://.

## Публикация

Создайте новый публичный репозиторий, например Project_2. Загрузите содержимое папки site (не саму папку): index.html, styles.css, script.js, assets целиком, .nojekyll. В Settings → Pages выберите Deploy from a branch, main и /(root), затем Save. Все пути относительные, поэтому сайт работает во вложенном адресе GitHub Pages. В репозитории Project_1 ничего заменять не нужно.

## Возможности

- Галерея рассвета, заката и ночи; переключение также стрелками клавиатуры.
- Две гостевые комнаты; выбор переносит название в контактное окно.
- Сценарий дня и ответы на вопросы перед поездкой.
- Интерактивная гостиная: часы меняют время суток, печь открывается, телефон показывает контакт, книга открывает трёхстраничную историю.
- Увеличенный просмотр с общим состоянием сцены, масштабированием и прокруткой.
- Полевые записи птиц и сверчков, плавная смена, громкость. Звук включается только по нажатию; скрытая вкладка затихает. Источники и лицензии: assets/audio/CREDITS.txt.
- Три открытки: предпросмотр и скачивание PNG 1200×940. Формируются в браузере, ничего не отправляется.
- Мобильная вёрстка, клавиатурное управление, поддержка уменьшения движения.

Это вымышленная учебная резиденция. Номер 123-45-67 демонстрационный; цены и реальный адрес не указаны. Кнопки не бронируют комнаты, ссылка tel: предлагает открыть приложение для звонка. Визуализации созданы ИИ по согласованной концепции. Новые промпты и ТЗ сохранены в соседней папке spec, для публикации она не требуется.
